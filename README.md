# 발음 감수실

음운 변동(교체·탈락·첨가·축약)을 배우는 국어 문법 게임. 학생은 가상 방송국 「소리방송」의 발음 감수관이 되어 아나운서 원고에 교정 부호 넷(고침표·뺌표·넣음표·합침표)으로 발음을 표시하고 송출한다. 아나운서는 교정한 대로만 읽고, 규칙 엔진이 표준 발음법에 따라 판정한다. 고1 공통국어1 [10공국1-04-02] 중심, 중3 다리 단계 포함. 「음운 해전」(sori-haejeon)의 다음 편.

- **바로 하기**: https://pblsketch.github.io/eumun-byeondong/
- **내려받아 하기**: 저장소를 받아 `index.html`을 더블클릭(인터넷 연결 없이 돈다).
- **지금 되는 것**: 8개 장 연습. 1 첫 출근(끝소리·연음), 2 닮은 소리(비음화·ㄹ의 비음화·유음화), 3 'ㅣ' 앞에서(구개음화), 4 세게(된소리되기), 5 자리가 하나(자음군 단순화·ㅎ 탈락), 6 덧나는 소리(ㄴ 첨가·반모음 첨가), 7 하나로(거센소리되기), 8 생방송(연쇄 변동, 지침 없이). 장마다 감수 지침 채우기 → 원고 7개 감수 → 실제 조항 공개 → 장 결과. 학년(중3/고1)과 단계(기본/심화)를 고를 수 있다. 3~8장의 몇몇 판단은 선생님 확인 전 잠정이다(`docs/tracking/decisions/0019`).
