# 0002 교정 부호 넷 = 변동 네 갈래

## 결정
- 조작 동사는 교정 부호 넷뿐이다: 고침표(교체)·뺌표(탈락)·넣음표(첨가)·합침표(축약, 게임 설정).
- 고침표는 소리 해전 체계표를 '조음 도표'로 열어 옮겨 갈 칸을 고른다(안 B: 닮아 가는 길이 보임).
- 장마다 '감수 지침' 빈칸을 예시로 채우고(안 C: 규칙 발견, 고르기로 묶음 확정), 장 끝에 실제 표준 발음법 조항을 공개한다.
- 어떤 부호든 어디에나 쓸 수 있다(막지 않는 오답). 판정은 송출할 때 규칙 엔진이 한다.
- 연음은 교정 대상이 아니다(자동 처리, 변동 0회).

## 결과
판정의 진실은 `G.rules` 음운 규칙 엔진에만 있다. 신호는 네 가지 이내(온에어 성공 / 결과는 맞지만 규칙 밖 교정 / n곳이 다름 / 표준 아님).
