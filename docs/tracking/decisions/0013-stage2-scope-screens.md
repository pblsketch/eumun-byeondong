# 0013 구현 2단계는 1·2장 연습 한 판, 화면 크기 세 종류

## 배경
구현 1단계에서 규칙 엔진과 1·2장 원고 82개가 생겼고 점검도 통과한다. 화면은 아직 없다. 선생님은 플레이 테스트를 수업 흐름 그대로 해 보고 판정·조작·문구를 검토하려 한다. 이번 결정은 구현 2단계 계획 인터뷰(2026-10-01)에서 나왔다.

## 결정 (2단계 계획 인터뷰, 2026-10-01)
- **목표**: 학생 한 명(또는 모둠)이 교실 기기에서 1·2장을 처음부터 끝까지 연습한다. 흐름은 시작 화면 → 감수 지침 → 원고 7개 감수·송출 → 조항 공개 → 장 결과다.
- **포함**: 시작 화면(학년·장·단계 고르기, 게임 방법, 설정), 감수 지침, 감수 화면, 조항 공개, 장 결과, 이어 하기(0016), 소리 장치와 음원 후보 목록, 화풍 견본, 글꼴(0017).
- **제외(다음 차례 이후)**: 3~8장, 대결(0006), 감수 수첩, 결과 화면의 알아 두기·생각해 볼 질문·캡처 제출, 자막 책상(0005), 실제 그림·음원 넣기와 '만든 사람·출처' 화면, 배포, 교사용 기능.
- **장 목록**: 8장 이름을 모두 보이고 1·2장만 누를 수 있다. 3~8장은 '준비 중'. 1·2장에는 중3에게 권한다는 표시를 둔다.
- **화면 크기 세 종류**: 태블릿·노트북 가로(1280×800, 1366×768), 휴대폰 세로(360×740, 390×844), 전자칠판(1920×1080). 모든 화면이 가로 스크롤 없이 쓰인다.
  - 누르는 자리는 가로 배치 64px 이상, 휴대폰 세로 48px 이상.
  - 휴대폰 세로에서 음절 블록이 한 줄에 안 들어가면 띄어쓰기·형태소 경계 자리에서 먼저 두 줄로 나눈다. 줄이 바뀌는 곳의 틈(넣음표 자리)도 누를 수 있게 남긴다.
  - 휴대폰 가로처럼 낮은 화면에서는 '세로로 돌려 주세요'를 보인다(음운 해전과 같음).

## 결과
- 도움 ③에 쓰는 쌍둥이 원고 함수는 나중에 대결에서도 쓴다(0015).
- 문구·이름표·송출 연출 시간·저장 이름 접두사·소리 자리 목록·휴대폰 가로 기준 높이 같은 기본값은 플레이 테스트 뒤 바뀔 수 있다.
