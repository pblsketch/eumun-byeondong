# 0004 반모음화는 교체

## 배경
기어→[겨ː], 보아→[봐ː]를 교과서마다 교체(반모음화) 또는 모음 축약으로 설명한다. 평가원은 2021학년도 9월 모평부터 교체로 다룬다. 국립국어원은 두 설명을 모두 인정한다. 근거는 `design/research/03_반모음_처리와_규범_검증.md`.

## 결정
선생님 판단대로 **교체**. 반모음(j, w)도 음운으로 센다. 단모음→반모음 = 교체, 없던 반모음이 생김 = 첨가(피어[피여]), 두 단모음 → 한 단모음 = 축약(보이다→뵈다). 게임 안에 기준 문구를 밝히고 "일부 교과서는 모음 축약으로 설명한다"를 덧붙인다.

## 결과
되어→돼처럼 분석이 갈리는 것은 원고에 넣지 않는다.
