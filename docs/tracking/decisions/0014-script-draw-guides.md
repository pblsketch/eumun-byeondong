# 0014 원고 뽑기 보강과 감수 지침

## 배경
0012는 장마다 무작위 7개(함정 2개, 변동 고루)를 정했다. 화면을 만들려면 어떤 원고를 빼고 함정을 어떻게 고를지, 감수 지침을 어떻게 채우고 채점할지 정해야 했다. 이번 결정은 구현 2단계 계획 인터뷰(2026-10-01)에서 나왔다.

## 결정 (2단계 계획 인터뷰, 2026-10-01)
- **원고 뽑기(0012 보강)**: 다시 해도 외워서 풀 수 없게 무작위 7개를 뽑는다.
  - 감수 지침의 예시 원고는 뽑지 않는다.
  - 1장: 함정 2개는 연음 함정 가운데, 일반 5개는 끝소리 규칙 원고 가운데서 뽑는다. 제15항 원고가 지침 예시로 쓰이고도 남아 있으면 적어도 1개 넣는다.
  - 2장: 함정은 **제20항 다만 1개 + 감기 1개로 고정**한다. 무작위로 두면 감기(위치 동화 함정)가 열 판에 두 번 꼴로만 나온다. 일반 5개에는 비음화(제18항)·ㄹ의 비음화(제19항)·유음화(제20항)가 각각 적어도 1개씩 들어간다.
  - 원고 갈래는 풀이 과정에서 끝소리 규칙이 아닌 첫 규칙으로 정한다(짓는·놓는 → 비음화, 막론·협력 → ㄹ의 비음화). 끝소리 규칙만 쓰면 끝소리 갈래, 함정은 함정 종류가 갈래다.
  - 7개의 순서와 함정 위치는 무작위다. 조건을 채울 수 없으면 함수가 오류를 던진다(데이터 잘못 — 점검이 잡음).
- **감수 지침**: 장마다 3개를 한 화면에 둔다. 실제 조항 원문에서만 만든다.
  - 1장: ① 끝소리 규칙(제8·9항) ② 형식 형태소 앞의 연음, 겹받침은 뒤엣것만 옮김(제13·14항) ③ 실질 형태소나 다음 단어 앞에서는 끝소리 규칙 뒤 연음(제15항)
  - 2장: ① 비음화(제18항) ② ㄹ의 비음화(제19항·붙임) ③ 유음화(제20항)와 '다만'
  - '다만'·겹받침 연음·제15항을 넣는 까닭: 빠지면 함정을 규칙으로 풀 수 없고 찍기가 된다.
- **빈칸과 예시**: 빈칸마다 보기 2~4개 가운데 하나를 고른다. 예시는 지침마다 3~4개로 **고정**하고, 빈칸 조건을 보기마다 적어도 한 번씩 보인다(점검이 엔진으로 확인). 무작위면 빈칸의 근거가 안 나올 수 있다.
- **채점은 틀린 칸 수만** 알린다("n칸이 맞지 않아요"). 어느 칸인지, 정답이 무엇인지는 알리지 않는다. 다 맞을 때까지 다시 고르고, 몇 번 틀렸는지는 기록하지 않는다.
- 장 결과에서 [다시 하기]로 같은 장을 다시 할 때는 지침을 건너뛴다.

## 버린 것
- 2장 함정도 무작위로 뽑기: 감기가 드물게 나온다.
- 지침 예시를 무작위로 고르기: 빈칸 근거가 빠질 수 있다.
- 지침을 3번 틀리면 정답 보기.
