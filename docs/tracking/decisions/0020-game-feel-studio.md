# 0020 게임다움: 스튜디오 무대·뉴스 한 줄·실제 그림을 넣는다

## 배경
선생님이 3~8장까지 들어간 판을 해 보고 "전혀 게임 같은 느낌이 안 들어 애들한테 매력적이지 않을 거 같다"고 했다(2026-10-02). 직접 해 보고 찾은 원인은 다섯 가지다.
1. **틀려도 아무 일이 없다.** 기획의 감정 엔진("교정을 잘못하면 아나운서가 생방송에서 그대로 틀리게 읽는다")이 화면에서 글자가 하나씩 나타나는 1.4초와 작은 '≠ 다름' 칩뿐이었다. 아나운서 그림 자리는 빈 틀이었고, 음원은 하나도 없었다.
2. **긴장 장치가 없다.** 송출 무제한·점수 없음·게임오버 없음(모두 교육 원칙)이 겹친 데다, 긴장을 맡을 대결 모드가 아직 없다.
3. **원고가 뉴스가 아니라 낱말 하나다.** 원고 377개 가운데 347개가 띄어쓰기 없는 낱말이고 평균 2.5음절이다.
4. **흐름과 겉모습이 학습지다.** 원문 빈칸 → 문제 7개 → 법조문 → 표 순서이고, 화면은 흰 카드와 테두리 단추뿐이다.
5. **그림을 만들지 않았다.** 화풍 B는 결정 0018에서 골랐지만 실제 에셋은 5단계로 미뤄진 채 3단계가 먼저 진행됐다. 시작 화면·감수 화면·프롬프터의 빈 점선 틀 세 곳이 '미완성' 신호로 보였다.

선생님은 "모두 개선해"라고 했다.

## 결정 (선생님 요청, 에이전트가 고친 것 — 플레이 테스트에서 확인)
- **그림(화풍 B, Codex CLI `tools/gen.ps1`)**: 두 아나운서의 상태 그림 다섯 장(기다림·읽기·당황·기쁨·갸웃 — 기준 그림 하나를 참조 그림으로 넣어 같은 얼굴로), 스튜디오 배경, 시작 화면 타이틀 그림, 선배 감수관. `tools/gen.ps1`에 참조 그림 모드(`-Image`, `-RefMode same|style`)를 더했고(음운 해전에서 가져옴), `tools/process_assets.py`가 자홍 배경을 지우고 책상 폭을 맞춰 `assets/img/*.webp`로 만든다. 프롬프트는 `tools/prompts/`, 기록은 `design/style-samples.md` '게임 그림'.
- **감수 화면 스튜디오 무대**: 프롬프터 상자를 스튜디오 무대로 바꿨다. 배경 그림 위에 두 아나운서가 앉고, 자막 띠 안에 프롬프터와 신호 배지가 있다. 송출하면 아래 순서로 진행한다(움직임 줄이기면 결과만 곧바로).
  1. 초읽기 3·2·1이 나온다.
  2. 아나운서가 '읽기' 그림으로 바뀌고 자막에 한 음절씩 읽는다.
  3. 결과가 나온다. 아나운서 그림이 바뀌고(온에어 → 기쁨, 다름 → 당황, 규칙 밖·표준 아님 → 갸웃), 무대를 가로지르는 결과 띠(방송 성공·방송 사고·PD 확인 요청·시청자 항의)와 시청자·PD 반응 두세 개가 한 번씩 나타난다.
  - 반응 글은 발음·위치·정답을 말하지 않는다.
  - 초읽기와 읽기를 합쳐 2초 안쪽이다(명세 §20의 1.5초에서 늘림).
  - 그림과 띠는 신호 종류만 보고 고른다. 판정은 그대로 `G.rules`가 한다.
- **뉴스 한 줄(`js/data/news.js`)**: 원고마다 짧은 뉴스 문장 하나를 두고 감수할 말을 펜 밑줄로 보인다. 음절 블록과 판정은 그 말만 다룬다.
  - 문장은 게임 설정(가상의 소리방송 뉴스)이다. 내용의 진실(원고 표기·발음·조항)과는 관계없다.
  - 감수할 말 바로 뒤에는 모음으로 시작하는 말을 붙이지 않는다(이어 읽으면 발음이 달라짐 — `check-data` 5절).
  - 377문장은 에이전트 초안이다.
- **펜 자국**: 교정한 자리에 교정 펜 색(새 토큰 `--pen`)으로 부호 모양이 남는다(고침 동그라미·뺌 빗금·넣음 꺾쇠·합침 고리). 오답 표시가 아니라 감수 흔적이다(`G.blocks.setPen`).
- **큐시트**: 감수 화면 머리 가운데(빈 그림 자리였던 곳)에 원고 7개의 차례와 결과(온에어·규칙 밖·넘김 — 장 결과와 같은 말)를 둔다. 점수나 누적 점수는 아니다.
- **단추 자리**: 한 줄 자리와 [되돌리기][도움][송출][다음 원고]를 책상 맨 아래 한 줄에 둔다(무대를 넣어도 송출 단추가 화면 아래로 밀리지 않게).
- **원고지 · 메모 · 선배**
  - 감수 책상은 줄 친 원고지 모양이다.
  - 교정 부호 단추는 아래 테가 두꺼운 '누르는 도구' 모양이고, 기호는 펜 색이다.
  - 감수 지침 카드는 테이프로 붙인 메모지(새 토큰 `--memo`)이고, 선배 감수관 그림과 말풍선을 둔다(처음·틀림·다 맞음에 한 줄씩).
  - 조항 공개 머리 문장은 선배의 말풍선 안에 넣었다. 조항 예시 가운데 이번에 감수한 말에 '이번에 감수한 말' 표를 단다.
  - 장 결과 머리에는 방송 마무리(모두 온에어면 활짝 웃는 아나운서 + '사고 없이', 아니면 기다리는 아나운서)와 온에어 수를 둔다.
- **새 색 토큰**(`css/base.css` — 역할을 섞지 않음): `--pen`·`--pen-soft`(교정 흔적), `--memo`·`--memo-line`(선배 메모), `--studio-*`·`--bubble`·`--stage-*`·`--lamp-*`(스튜디오 무대).

## 바꾸지 않은 것
- 판정·뽑기·채점·저장 모양(엔진과 저장 점검 그대로), 오답을 막지 않음, 게임오버 없음, 랭킹·점수 없음, 답이 새지 않음.
- 소리: 음운 해전 결정 0011(합성음을 쓰지 않음)에 따라 효과음을 코드로 만들지 않았다. 음원은 선생님이 `design/audio-candidates.md`에서 고른 뒤 넣는다. 고르면 내려받아 넣는 일은 에이전트가 한다.

## 버린 것
- 책상과 무대를 가로로 나란히: 가로 화면에서 4음절 원고가 두 줄로 나뉘어(점검이 막음) 책상 너비 가득을 지켰다.
- 효과음 합성: 시리즈 결정 0011.
- 시청자 반응에 점수·시청률 숫자: 랭킹·점수 없음 원칙(결정 0006).
