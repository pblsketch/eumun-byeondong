# 0001 게임 틀은 방송국 '발음 감수실'

## 배경
처음 안은 소리 해전 기획안의 가칭 '소리 부엌'(표기를 손질해 발음을 요리)이었다. 선생님이 "부엌 비유가 자칫 유치해질 수 있다"고 했다. 대안으로 발음 감수실(방송국), 보이스 랩(AI 음성 엔진), 소리 반응 실험실을 비교했다.

## 결정
제목과 틀은 **「발음 감수실」**. 학생은 가상 방송국의 발음 감수관이 되어 아나운서 원고(표기)에 교정 부호로 발음을 표시하고 송출한다. 아나운서는 교정한 대로만 읽는다.

## 버린 것
- 소리 부엌: 고1에게 유치할 수 있다.
- 보이스 랩: 음성 엔진이 주제인데 소리 없이 진행해야 해 어색하다(시리즈가 합성음을 이미 뺐다).
- 소리 반응 실험실: 화학 반응은 입자 수가 보존되는데 탈락·첨가는 아니어서 비유가 오개념을 부를 수 있다.

## 결과
실제 방송사 이름·로고·인물은 쓰지 않는다. 표준 발음법 조항은 실제 문서로 인용하고, 방송국·합침표 등은 '게임 설정'으로 표시한다.
