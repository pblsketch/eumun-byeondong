# 0022 시작 화면과 화면 제목에 그림을 더함

## 배경
선생님이 휴대폰 세로 크기의 시작 화면을 보고 "너무 재미없어 보인다, 밋밋하다"고 했다(2026-10-02). 원인은 두 가지였다.
- 시작 화면의 타이틀 그림(결정 0020)이 휴대폰 세로에서는 숨겨져, 화면에 글과 단추만 남았다.
- 장 카드 8개가 번호와 글만 있는 같은 모양의 상자였다.

다른 화면도 살펴보았다. 감수 · 지침 · 조항 공개 · 장 결과에는 아나운서와 선배 그림이 있다. 게임 방법 창은 글 카드뿐이었고, 지침 · 조항 공개 · 장 결과 제목은 글만 있었다.

## 결정
- **그림 세 묶음을 Codex(`tools/gen.ps1`, 화풍 B)로 만들었다.** 목록과 참조 그림은 `design/style-samples.md` '게임 그림' 표에 있다.
  - `start_banner`: 손을 흔들어 새 감수관을 맞는 두 아나운서. 타이틀 그림을 참조(`same`)해 같은 인물로 그렸다.
  - `chapter_badges` → `ch1`~`ch8`: 장마다 그 장의 변동을 빗댄 동그란 배지.
  - `ui_icons` → `ic_*` 8개: 지침 · 원고 감수 · 조항 공개 · 장 결과 · 음절 블록 · 교정 부호 · 송출 · 도움을 나타낸다.
- **시작 화면**
  - 휴대폰 세로 · 좁은 화면에서는 제목 아래에 머리 그림을 보인다. 넓은 화면에서는 오른쪽 타이틀 그림이 그대로 있고, 머리 그림은 숨긴다.
  - 머리 그림의 온에어 등 자리가 깜박인다.
  - 장 카드 모양
    - 왼쪽에 장 배지를 둔다. 장 번호는 배지 왼쪽 위의 동그란 딱지다. 이름은 배지 오른쪽에, 풀이 한 줄은 카드 너비 전체에 둔다.
    - 고른 장의 배지는 살짝 기울며 커진다.
    - 음운 표기(/ㅣ/)는 줄에서 끊기지 않는다.
  - [감수 시작] 단추에 빛이 한 번씩 훑고 지나간다.
  - 동작 줄이기를 켜면 깜박임과 빛줄기가 멈춘다(base.css의 공통 규칙).
- **다른 화면**
  - 감수 화면 머리 왼쪽에 그 장의 배지를 둔다.
  - 지침 · 조항 공개 · 장 결과 제목 옆에는 아이콘을 둔다(메모 · 규칙 책 · 우승컵).
  - 게임 방법 카드
    - 카드마다 제목 줄 오른쪽에 그림을 둔다.
    - 2번 카드(한 장의 흐름)에는 지침 → 원고 감수 → 조항 공개 → 장 결과 네 그림을 차례로 둔다.
- **꾸밈 그림의 규칙**
  - 그림은 모두 꾸밈이다. alt를 비우고 보조 기술에서 숨기며(`G.util.art`), 뜻은 옆의 글이 말한다.
  - 머리 그림만 `role="img"`와 설명(`TEXT.images.startBanner`)을 단다(타이틀 그림과 같은 방식).
- 그림에는 글자 · 숫자 · 로고 · 실제 방송사 · 조선 소재가 없다. 도미노의 점은 무늬이고 숫자가 아니다.

## 버린 것
- **장 카드를 큰 그림 위주의 '단계 고르기' 카드로 만들기**: 휴대폰 세로에서 카드 8개가 화면 두 배 길이가 되어 [감수 시작]이 너무 멀어진다.
- **휴대폰 감수 화면에서 스튜디오 무대를 맨 위로 올리기**: 블록과 교정 부호가 화면 아래로 밀린다. 송출하면 무대로 스크롤하는 지금 흐름(결정 0020)을 그대로 둔다.

## 선생님이 확인할 것
- 장 배지의 빗댐이 장 내용과 어울리는지(목록은 `design/style-samples.md`). 특히 3장(굴러가는 공)과 5장(방석 하나만 남은 의자).
- 머리 그림 · 아이콘의 느낌.
