# 0018 아나운서는 남녀 두 명이 함께 진행, 화풍은 B(부드러운 그림책)

## 배경
기획안과 2단계 명세는 '가상 아나운서 1명'이었고, 화풍 견본 세 장(`design/style-samples/`)은 모두 여자 아나운서 한 명으로 그렸다. 견본을 본 선생님이 "남자 아나운서도 필요하지 않아?"라고 물었다(2026-10-01).

## 결정 (선생님)
- **아나운서는 남녀 두 명**이 뉴스 스튜디오처럼 나란히 앉아 **함께 진행**한다(원고를 나눠 읽음). 두 사람 모두 가상 인물이다(실제 인물 없음).
- **화풍은 견본 B(부드러운 그림책)**. 공통 화풍 문구와 프롬프트는 `design/style-samples.md`의 B.
- 견본은 다시 그리지 않는다. 실제 그림을 넣을 때 화풍 B로 두 아나운서를 그린다.

## 결과
- 2단계(이번 작업)는 그림 자리를 비워 두므로 화면 동작은 바뀌지 않는다.
- 두 사람이 원고를 어떻게 나눠 읽는지(원고마다 번갈아, 음절마다 등)와 대결 모드에서의 역할은 그림을 넣는 단계에서 정한다.

## 버린 것
- 남녀 두 명 중 학생이 고르기, 대결에서 청·홍에 한 명씩: 선생님이 '함께 진행'을 골랐다.
- 지금 견본 다시 그리기: 화풍부터 고르고 나중에 그린다.
