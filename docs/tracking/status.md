2. **구현 1단계 — 규칙 엔진과 원고 데이터 (화면 없음)**
   - `js/data/sounds.js`: 소리 해전에서 가져와 반모음 j·w 추가.
   - `js/core/rules.js`: 음운 열(음절 자리: 초성·중성·종성) + 형태소 경계 + 낱말 표시(예외) → 적용 가능한 규칙, 교정 하나의 규칙 안/밖 판정, 표준 발음 도출, 음운 수 변화.
   - `js/data/scripts.js`: 1·2장 원고(표기, 형태소 분석, 표준·허용 발음, 풀이 과정, 조항, 함정 여부).
