# 개인정보·네트워크·저장 정책

## 지키는 것

- **학생 개인정보**: 받지 않는다. 이름·번호·반·계정 입력이 없고, 화면 어디에도 학생을 가리키는 칸이 없다. 앞으로 결과 캡처 제출이 생겨도 이름을 저장하지 않는다.
- **네트워크**: 게임은 아무것도 보내지 않는다(분석·통계·광고·오류 보고 없음). 불러오는 것은 같은 출처의 동봉 파일(`assets/fonts/*.woff2`, 앞으로 `assets/audio/*.mp3`·그림)뿐이다. CDN·웹 글꼴 서비스·외부 이미지 주소를 쓰지 않는다. `index.html`·CSS·JS에 `http://`·`https://`로 시작하는 바깥 주소가 생기면 결함이다.
- **기기 저장**: localStorage에 `eumun-byeondong:` 접두사 값 넷만 쓴다 — 설정(소리 켜기·음량·움직임 줄이기), 마지막 선택(학년·장별 단계), 게임 방법을 연 적, 진행 중인 장(원고 id·교정·송출 신호·도움 단계). 이름·점수·답안 이력은 없다. 공용 기기에서 다음 학생이 이어 하기 카드로 앞 학생의 진행 장을 볼 수 있다는 것은 받아들인 일이다(덮어쓰기 전 한 번 묻는 것으로 처리).
- **답 새지 않기(학습 공정성)**: 결과 전에는 뽑힌 원고의 표준 발음·비표준 발음·함정 여부·갈래, 지침 정답, 심화 단계의 형태소 경계·이름표가 화면 글·DOM 속성·aria 어디에도 없어야 한다. 데이터 파일(`window.SCRIPTS` 등)은 페이지에 실려 있어 개발자 도구로는 볼 수 있다 — 이는 받아들인 한계다(서버가 없는 정적 게임). 막는 대상은 화면과 DOM이다.

## 저작권·출처

- 글꼴: Pretendard(SIL OFL 1.1) 수정본. OFL에 따라 이름을 GamsuPron·GamsuUI로 바꾸고 `assets/fonts/OFL-Pretendard.txt`에 원 저작권 표시와 라이선스 전문을 둔다. 원본 OTF는 저장소에 올리지 않는다.
- 교과서 PDF(지학사 연구용 교과서·지도서)는 저장소에 올리지 않는다. 대조 결과만 `design/research/03`에 쪽수와 함께 적는다.
- 음원은 자유 이용 녹음 음원만 쓰고, 넣을 때 `assets/audio/CREDITS.md`에 출처·라이선스를 적는다. CC BY 음원을 넣으면 게임 안에 '만든 사람·출처' 화면이 있어야 한다.
- 실제 방송사 이름·로고·인물, 실존 아나운서를 쓰지 않는다. 방송국은 가상의 「소리방송」, 아나운서는 가상 인물(남녀 두 명)이다.

## 실패해도 안전하게

- 저장소가 막혀 있거나(시크릿 창·정책) 용량이 넘쳐도 게임은 이번 세션 동안 메모리로 돈다. 저장 함수는 예외를 던지지 않는다.
- 음원 파일이 없거나 풀리지 않아도 조용히 넘어간다(파일마다 경고 한 번).
- 저장된 진행 장이 망가졌거나 지금 데이터와 맞지 않으면 오류 없이 버리고 시작 화면으로 간다.
