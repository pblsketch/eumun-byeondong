# js/data — 학습 데이터와 화면 문구 (선생님이 고치는 곳)

## 맡는 것
- `sounds.js` → `window.SOUNDS`: 자음 19·단모음 10의 자질(음운 해전 자질 그대로) + 반모음 j·w + 이중 모음 분해표(ㅢ는 나누지 않음).
- `scripts.js` → `window.SCRIPTS`: 원고 377개(1장 31·2장 56·3장 16·4장 87·5장 66·6장 61·7장 31·8장 29). 표기·형태소 분석·경계·낱말 표시·표준 발음·허용·흔한 비표준 발음·풀이 과정·음운 수·변동 횟수·조항·출처·함정 종류.
- `articles.js` → `window.ARTICLES`: 표준 발음법 조항 원문(제8·9·12·13·14·15·18·19·20·20 다만·21항), 현행 고시 문장 그대로.
- `guides.js` → `window.GUIDES`: 1~7장 감수 지침(1·2·4·5·6·7장 3개, 3장 2개 — 빈칸·보기·정답·예시 원고·예시가 보이는 조건). 8장은 키가 없다(지침 없이 감수부터).
- `text.js` → `window.TEXT` + `G.text`: 화면 문구 전부(학년별 `{ m3, h1 }`), 문구 도우미(`fill`·`t`·`pron`·`signal`·`cutLabel`·`logLine` …).

## 맡지 않는 것
- 판정 — 데이터는 엔진(`js/core/rules.js`)이 검증한다. 원고에 맞춰 엔진을 고치거나 엔진에 맞춰 원고의 발음을 바꾸지 않는다(둘이 다르면 원문과 대조).
- 화면 배치·모양(`js/game/*`, `css/*`).

## 불변 조건
- 원고·지침 예시·조항 문장은 원문 대조본(`design/research/03` — 표준 발음법·한글 맞춤법 원문, 지학사 교과서, 현행 고시 대조)에 있는 것만 쓴다. 원고마다 `src`에 조항·쪽을 적는다. 대조되지 않은 예시(읽고, 밭이랑 등)와 분석이 갈리는 낱말(되어→돼 등)은 넣지 않는다.
- 원고는 엔진 대조를 통과해야 한다: 엔진 도출 = `pron`, `steps`의 모든 단계가 규칙 안, `count`·`change`가 단계와 맞음. 받침 ㅎ + ㄴ은 교체 2회(놓는: ㅎ→ㄷ→ㄴ). 연음은 단계에 넣지 않는다(0회).
- 2장 뽑기는 다만 함정 1 + 감기 1을 고정으로 뽑는다 — 감기(유일한 표준 아님 함정)를 지침 예시로 쓰면 뽑기가 오류를 던진다. 1장은 연음 함정이 지침 예시를 빼고 2개 이상, 제15항 일반 원고가 1개 이상 남아야 한다.
- 지침: 빈칸마다 보기 2~4개(빗금 표기), 답 하나. 예시들의 `shows`가 빈칸 `members`를 모두 덮는다. 두 학년 문장의 빈칸 자리가 같다. 조건 낱말은 `js/core/rules.js` 머리 주석의 어휘만(`coda:`·`coda2:`·`onset:`·`before:`·`cut:`·`gap:`·`cv:`·`link`·`exc`·`stem`·`adn`·`sai`·`cexc`·`noins`·`vowelI`).
- 지침 문장은 그 장 어느 빈칸의 정답도 그대로 담지 않는다(3~7장 점검). 보기 차례에 정답 자리가 몰리지 않게(늘 첫 보기가 정답이면 안 됨). 3장 일반 예시는 6개까지, 7장 함정 예시는 하나까지(뽑기 여유 — findings F11). 지침 예시를 바꾸면 `check-rules` 8절의 '시드 200개 뽑기'가 통과하는지 본다.
- 문구: 규칙 이름(`terms.rule`)은 엔진 규칙 id마다 둘 다(중3 우리말 · 고1 용어). 경계 이름표 `terms.cut.stem`은 어간 + 어미 경계(기본 단계).
- 문구: 음운은 빗금, 대괄호 없음(발음은 `G.text.pron`이 채움 — 실제 낱말의 발음을 문구에 적지 않음), 한자·'글자'·'게임오버'·실제 방송사·훈민정음·조선 소재 없음, 한 줄(줄바꿈 문자 없음), 한 줄 자리는 대략 30자. 두 학년의 키 구조와 `{이름}` 자리가 같다.
- 데이터는 `window.이름 = …`으로 내보낸다(최상위 `const`로 두면 Node 점검이 못 읽음).

## 구현 방식
- 원고 자리 글(`'0.co'`·`'1.on'`·`'0.co1'`)은 음절 번호.자리(+종성 안 번호). 경계 `cuts`는 음절 수 − 1개, 형식(조사·어미·접미사 앞)·실질(어근 앞)·한자어 구성(제20항 다만 낱말만)·띄어쓰기·없음.
- 학년별 문구가 필요하면 `{ m3: …, h1: … }`로 두고, 같은 문구면 문자열 하나로 둔다. 짧은 이름은 `shortTerms`.
- 문구를 고쳐 새 글자가 생기면 글꼴을 다시 만든다(`python tools/build_fonts.py`).

## 점검
- `cd tests && npm test -- rules data check-text`(`text`만 주면 브라우저 점검 `check-screen-text`도 돈다).
- `check-data`: 조항 원문 키가 다 있음, 제15항 원고 대조, 지침 데이터 모양.
- `check-text`: 두 학년 키 구조, 금지 낱말·한자·빗금 없는 자모·대괄호·줄바꿈.
- `check-rules`: 원고 엔진 대조, 지침 예시 검증(`checkGuides`가 빈 목록), 모든 시드에서 뽑기 조건.
- 원고나 지침을 고치면 교실 기기에 저장된 진행 장이 확인에서 걸러져 버려질 수 있다(원고 id·지침 차례가 바뀌면).
