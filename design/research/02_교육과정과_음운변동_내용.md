## 2. 내용 체계 [미검증 — 원문 대조 필요]

### 2-0. 선수 지식 = 소리 해전의 체계표

| 방법 \ 위치 | 입술 | 잇몸 | 센입천장 | 여린입천장 | 목청 |
|---|---|---|---|---|---|
| 파열음 (예사/된/거센) | ㅂ ㅃ ㅍ | ㄷ ㄸ ㅌ | | ㄱ ㄲ ㅋ | |
| 파찰음 | | | ㅈ ㅉ ㅊ | | |
| 마찰음 | | ㅅ ㅆ | | | ㅎ |
| 비음 | ㅁ | ㄴ | | ㅇ | |
| 유음 | | ㄹ | | | |

체계표 위에서 보면: **비음화 = 같은 세로줄(위치)에서 비음 줄로 이동**, **구개음화 = 가로로 센입천장 줄로 이동**, **된소리되기 = 같은 칸에서 세기만 변함**, **거센소리되기 = ㅎ과 합쳐져 거센 칸**.

|---|---|---|---|
| 음절의 끝소리 규칙 | 음절 끝에서는 ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅇ 7개만. ㄲ·ㅋ→ㄱ / ㅅ·ㅆ·ㅈ·ㅊ·ㅌ·ㅎ→ㄷ / ㅍ→ㅂ | 부엌[부억], 옷[옫], 낮[낟], 꽃[꼳], 밭[받], 앞[압] | 제8·9항 (연음 제13항, 실질 형태소 앞 제15항: 겉옷[거돋]) |

### 2-5. 음운 수 변화와 연쇄 변동

교체 = 그대로, 탈락 = −1, 축약 = −1, 첨가 = +1. **수능·내신의 단골 출제점.**

| 단어 | 과정 | 유형·횟수 |
|---|---|---|
| 닭만[당만] | ㄺ→ㄱ, ㄱ→ㅇ | 탈락 1, 교체 1 |
| 홑이불[혼니불] | ㄴ 첨가, ㅌ→ㄷ, ㄷ→ㄴ | 첨가 1, 교체 2 |
| 넓죽하다[넙쭈카다] | ㄼ→ㅂ, ㅈ→ㅉ, ㄱ+ㅎ→ㅋ | 탈락 1, 교체 1, 축약 1 |
| 꽃잎[꼰닙] | ㄴ 첨가, ㅊ→ㄷ, ㄷ→ㄴ | 첨가 1, 교체 2 |
| 굳히다[구치다] | ㄷ+ㅎ→ㅌ, ㅌ→ㅊ | 축약 1, 교체 1 |
| 끓는[끌른] | ㅀ→ㄹ, ㄴ→ㄹ | 탈락 1, 교체 1 |
| 막론[망논] | ㄹ→ㄴ, ㄱ→ㅇ | 교체 2 |

**자주 나오는 문제 유형**: 변동 유형 분류 / 음운 개수 변화 / 같은 변동을 공유하는 단어 쌍 / 표기에 반영된 변동 찾기 / 조항 자료로 예외 설명 / 적용 순서 판단.

### 2-6. 학생 오개념 (게임이 '함정'으로 일부러 넣을 것)

1. 연음을 변동으로 센다 — 옷이[오시]는 변동 0회.
2. 표기 기준으로 음운을 센다 — 초성 'ㅇ'을 음운으로 셈.
3. 끝소리 규칙(교체)과 자음군 단순화(탈락)를 구별 못 함.
4. 구개음화 과잉 적용 — 잔디, 마디(한 형태소 안). 밭이랑[반니랑]은 ㄴ 첨가.
5. 실제 발음을 표준으로 착각 — 감기[강기], 신문[심문]은 **비표준**(제21항, 위치 동화 불인정).
6. ㅎ 탈락과 거센소리되기 혼동 — 좋아[조ː아] 탈락 / 좋고[조ː코] 축약.
7. **반모음 처리가 교과서마다 다름** — 기어→[겨ː]를 교체(반모음화)로 볼지 모음 축약으로 볼지. **게임 안에서 기준 하나를 정해 밝혀야 함.**
8. 표기에 반영되는 변동(ㄹ·ㅡ·동음 탈락, 모음 축약)과 반영 안 되는 변동 구분.

## 3. 교수 전략 (게임에 옮기기 좋은 것)

1. **귀납적 규칙 발견**: 예시 묶음(국물·밥물·닫는)에서 공통 조건을 가설로 → 반례(감기[강기], 잔디)로 검증. 교육과정의 "원리나 규칙을 발견하는 과정을 체험"과 같은 방향.
2. **체계표 위 이동 시각화**: 비음화 = 세로, 구개음화 = 가로.
3. **음운 칸 세기**: 바뀜·사라짐·생김·합쳐짐을 다르게 표시 → 음운 수 변화가 저절로 보임.
4. **적용 순서 배열**: 연쇄 변동 단어.
5. **생활 속 발음 성찰**: 일상 발음(신문[심문])을 조항으로 판정.
