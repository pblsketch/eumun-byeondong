## 2. 공통 제안: 상태 모양·엔진에 더할 것

### 2-1. 장 배정 원칙 (D0-1)
**누적**: N장 원고는 1~N장 규칙만 쓴다(교과서 차례 3→8). 그래서 3장 원고는 구개음화 한 번뿐이고, 5장 원고는 단순화 뒤 된소리(4장 규칙)를 쓸 수 있으며, 넓죽하다·굵직한(축약 필요)은 5장이 아니라 7·8장이다. 표의 배정은 이 원칙을 따랐다.

### 2-3. 엔진에 필요한 일 (구현 메모)
1. **겹받침 열기**: `applicable`은 지금 `y.co.length !== 1`이면 건너뛴다. 5장(단순화·ㅎ 탈락)뿐 아니라 3장 벼훑이(/ㄾ/의 /ㅌ/), 4장 제14항(값을의 /ㅅ/→/ㅆ/), 7장 많고·밝히다(겹받침 뒤엣것 + /ㅎ/ 합침)가 모두 겹받침 자리 교정이다.
2. **연음 안내(touchedLink) 예외**: 연음 자리의 받침을 고침표로 바꾸는 것이 **정답인** 원고가 생긴다 — 구개음화(굳이 0.co), 제14항 된소리(값을 0.co1). 이 교정이 규칙 안이면 "연음은 소리가 바뀐 것이 아니에요"를 띄우지 않아야 한다. 뺌표(ㅎ 탈락: 낳은 0.co)도 마찬가지.
3. **받침 /ㅎ/ (findings F4)**: 5장 `h-drop`(모음·/ㄴ/ 앞 탈락), 7장 `aspirate`(/ㄱ·ㄷ·ㅈ/ 앞 합침)가 들어오면 F4의 위험이 사라진다. 그때도 **어말 /ㅎ/**(히읗[히읃])·**/ㅎ/+/ㅅ/**(닿소[다ː쏘], D7-4)은 여전히 열리지 않는다.
4. **받침 /ㅈ/ + /ㅎ/ (D7-2)**: 지금 `coda` 규칙은 /ㅈ/을 /ㅎ/ 앞에서도 /ㄷ/으로 바꾼다(엔진 도출: 잊히다 → [읻히다], 꽂히다 → [꼳히다]). 제12항 [붙임 1]은 /ㅈ/+/ㅎ/을 곧바로 [ㅊ]으로 합친다. 그대로 두면 꽂히다를 /ㅈ/→/ㄷ/ ▸ /ㄷ/+/ㅎ/→/ㅌ/ ▸ /ㅌ/→/ㅊ/(구개음화 [붙임])로 세 번 고쳐도 모두 규칙 안이 되어 같은 [꼬치다]에 닿는다.
5. **합침**은 이미 있다(`merge`, 종성+초성은 초성 자리에 남음 — 놓고 → [노코]). **넣음**도 빈 초성·빈 반모음 자리에 된다(꽃잎 1.on, 피어 1.gl). 새 op는 필요 없다.
6. **반모음화(7장, D7-1)**: '단모음 /ㅣ·ㅗ·ㅜ/ → 반모음'은 지금 `replace`로 할 수 없다(`fits('nu','j')`가 거짓). 고친 반모음이 **뒤 음절의 반모음 자리로 옮겨 가고 앞 음절 초성도 따라가는**(기어 → 겨) 재음절화가 필요하다. 보아·기어·두어는 그래서 엔진 대조를 하지 못했다(`manual`).
7. **조건 낱말(지침 예시 확인용)** 새로: `stem`(marks.stem 있음), `adn`, `sai`, `cexc`(clusterExc), `noins`, `gap:K`(빈 초성이 아니어도 경계 종류 K — 제26·28항은 초성이 있는 자리), `cv:ㄷㅣ`(한 형태소 안 /ㄷ/+/ㅣ/ — 잔디), `vowelI`(빈 초성 + /ㅣ/ 또는 /j/ — 제29항).
8. **조항 키**: `ARTICLES`에 새로 '10'·'10-다만'·'11'·'11-다만'·'12'(전체 — 지금은 3만 있음)·'14'(괄호 포함, 이미 있음)·'17'·'22'·'23'~'30'·'29-다만'·'26-다만'·'6'(붙임)이 필요하다(D0-4). 문장은 부록 A.

### 2-4. 원고 데이터 모양
`candidates.json`의 원고는 `scripts.js`와 같은 필드에 다음을 더했다: `verify`(확인 수준), `note`, `pending`(4절 결정 번호), `alt`(허용 발음으로 가는 풀이 — 제22항·제30항 1), `altCount`·`altChange`, `caption`(자막 책상 표기 — 7장 모음 쪽), `engineNow`(지금 엔진의 도출 발음과 단계별 규칙 안 여부: 규칙 id = 지금도 규칙 안, `-` = 새 규칙 필요). 넣을 때는 `verify`·`note`·`engineNow`를 빼면 된다.

**표 읽는 법**: cuts는 음절 사이마다 한 글자 — 형 = `formal`, 실 = `content`, 띄 = `space`, 한 = `sino`, · = `null`. 풀이는 `규칙 id 교정 자리 음운`, ▸ = 다음 교정. 음운 수는 03·business-rules 셈법(빈 초성 0, 이중 모음 2, ㅢ 2, 겹받침 2, 된소리·쌍받침 1)으로 엔진 `phonemes`가 셌다.

### 8장 생방송 — 연쇄 변동 (지침 없음)

- 새 규칙은 없다. 원고마다 3~7장 규칙이 **둘 이상** 걸리고, 다음 차례가 상태로 정해진다:
  - **탈락이 먼저**: 흙만·긁는·없는·읊는·밟는·값 매기다·흙 말리다·몫몫이 — 겹받침에는 비음화가 걸리지 않는다(`applicable`이 홑받침만 봄). 기획안 닭만의 자리.
  - **끝소리가 먼저**: 옷 한 벌·꽃 한 송이 — /ㅅ/+/ㅎ/ 합침은 규칙 밖(제12항 [붙임 2]).
  - **축약이 먼저**: 굳히다·닫히다·묻히다·닫히고 — 합쳐서 생긴 /ㅌ/에 구개음화(지공1 113, 지화언 31, 지공1지도 145).
  - **첨가 → 비음화**: 홑이불·꽃잎·밭이랑(명사)·옷 입다 — 첨가된 /ㄴ/ 앞에서 /ㄷ/→/ㄴ/. 끝소리 고침과 첨가의 차례는 자유(둘 다 규칙 안).
  - **예외 표시**: 넓죽하다·밟는(clusterExc), 결단력(제26항 + 제20항 다만).
- 함정은 따로 두지 않았다(3개는 예외 표시 낱말). 8장 뽑기 조건은 D8-1.

## 4. 선생님께 여쭐 것 (결정 필요)

각 항목: 무엇이 갈리는가 · 선택지 · 추천(결정 아님).

**공통**
- **D0-1 장 배정** — 원고가 앞 장 규칙을 함께 써도 되는가. (가) 누적(N장은 1~N장 규칙): 5장에서 단순화+된소리 가능, 3장은 구개음화 한 번뿐. (나) 그 장 규칙만: 5장은 넋·닭·낳은 같은 1회짜리만 남아 원고 19개. (다) 아무 장 규칙이나. → **추천 (가)**. 3장 일반이 11개라 예시를 빼면 빠듯하다 — 곧이듣다([고지듣따], 된소리 4장)를 3장에 허용할지도 함께.
- **D0-2 함정 갈래** — 새 이름 `blocked`(교정 없음이 정답)와 `contrast`(다른 부호가 정답)를 들일지, 3~8장 뽑기 조건(장마다 함정 2 + 일반 갈래 고루). → 추천: 두 이름을 들이고, 뽑기는 1·2장처럼 함정 2(종류 다르게) + 일반 5(그 장 규칙 갈래가 적어도 하나씩).
