## 1. 시리즈의 핵심 설계 철학 (여러 편에 되풀이됨)

| 원리 | 선생님이 쓴 말 (요지) | 적용 예 | 출처 |
|---|---|---|---|

| 인출 연습·간격 효과 | "인출을 조작으로 만든다" | 소리 해전 3단계: 이름을 숨겨 도움 없이 떠올리게 함 | S02 §2.9 |

| 내재적 보상 | 수집 대상은 모두 이해와 연결. 랭킹·뽑기·경험치·연속 접속 보상 금지 | 소리 해전 누적 '음운 지도', 사씨 호칭 도감 | S03 §1.8 |
| 표시 체계·출처 감시 | 원문/풀이/게임 설정/해석/이본 노트를 색으로 구분. 해석이 갈리는 곳은 채점하지 않음 | 소리 해전: /ㅎ/은 세기 없음으로 채점 | S02 §5 |
| 접근성 | 색과 기호를 함께, 움직임 줄이기, 큰 터치 목표, 소리 없이 완주 | 전 편 | S02 §6.3 |

### 소리 해전에서 새로 생긴 것

- 판 화면 문구는 늘 한 줄. 여러 줄 안내는 학생이 여는 '게임 방법' 창에만 둔다(0012).
- 몸으로 겪기: '따라 해 보기' 말풍선, 대결에서 "소리 내어 외치고 발사!"
- 숨긴 정보는 화면 글·DOM·aria 어디에도 새지 않게 한다.
- 교사 리모컨·`?teacher=1` 없음(0007). 학생이 단계를 고르고 잠금이 없다.
- 학년 차이는 **용어만**(중3 우리말, 고1 우리말+한자어). 규칙에는 학년 분기를 두지 않는다.

## 3. 기술 구조 (다음 편이 따를 관례 — 소리 해전 기준)

- HTML + CSS + 순수 JS. 빌드·프레임워크·npm 의존성·서버 없음. file:// 더블클릭과 GitHub Pages 모두 동작.
- `<script>` 층 순서: util → data → core → game → main. 전역은 `window.G` 하나.
- `js/data/`(선생님이 고치는 데이터, 화면 문구는 모두 `TEXT`에), `js/core/rules.js`(순수 함수 규칙 엔진), `js/game/`(화면 부품). 짝 CSS는 `css/<이름>.css`.
- 저장은 localStorage `<게임>:` 접두사 + 스키마 버전. 서버 전송 없음.
- 문서: `CLAUDE.md`=`AGENTS.md`, 폴더별 `AGENTS.md`, `docs/`(architecture·business-rules·contracts·standards·security·operations), 결정 기록 `docs/tracking/decisions/NNNN-*.md`.
- 커밋 메시지는 한국어.

## 5. 새 게임에서 먼저 정해야 할 것 (선행작과 충돌하는 지점)

1. **표기 규칙**: 소리 해전은 "음운은 `/ㄱ/`, '글자'라는 말 금지". 음운 변동은 **표기와 발음의 구분이 핵심**이므로 `[궁물]` 발음 표기와 표기를 부르는 말의 규칙이 새로 필요하다.
2. **장르**: '갈래가 바뀌면 장르도 바뀐다'. 음운 변동은 격자가 아니라 **과정(앞뒤 소리가 만나 바뀌는 일)** 이므로 해전과 다른 뼈대가 맞다.
3. **이미 버린 것**: 교사 리모컨, 3D, 합성음, 훈민정음·조선 소재, 판 도중 긴 설명, 신호 종류 늘리기.
4. **휴대폰 배치**: 소리 해전의 못 푼 문제(좁은 칸에서 표기와 배지 겹침). 처음부터 여유 있게.
